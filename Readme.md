# ATU Student Study Planner Web Application

A clean, responsive, and feature-rich Student Study Planner web application built for the Accra Technical University (ATU) Virtual Internship Software Development Individual Mini Project.

## Features

- **Task Management:** Add study tasks with custom titles and course or subject names.
- **Task Completion:** Mark tasks as completed, return them to pending, or delete them.
- **Task Timers:** Set optional due dates and times for study tasks.
- **Live Countdown:** View a countdown that updates every second for each task.
- **Timer Alerts:** Timers pulse when they are within one hour and show an overdue state after the deadline.
- **Persistent Storage:** Tasks and their timer settings are saved with browser `localStorage`.
- **Progress Tracking:** View total, completed, and remaining task counts with a progress bar.
- **Task Filtering:** Filter the task list by all, pending, or completed tasks.
- **Interactive Notifications:** Receive toast feedback when tasks are added, completed, or deleted.
- **Theme Switcher:** Seamlessly switch between light and dark modes.
- **Live Academic Clock:** Display the current local time and date.
- **Input Validation:** Prevent blank task titles and provide helpful feedback.
- **Responsive Design:** Works across desktop, tablet, and mobile screen sizes.

## Technologies Used

- HTML5
- CSS3 with responsive Flexbox and Grid layouts
- Vanilla JavaScript
- Browser Local Storage API
